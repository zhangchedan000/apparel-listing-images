# TK Apparel Visuals · 美区服装图 Skill

当前文件夹是安装用单独Skill；仓库根目录原有`SKILL.md`继续保留亚马逊和TK的共用工作流，新TK规则优先以本文件夹为准。下载`skill.zip`并安装到支持自定义Skill的环境。

用法示例：`TK美区，纯卖点图，2–3张，先分析清单`；`3PCS组合装按层叠模板`；`做不露脸上衣模特图`；`把这张图片转TK尺寸并统一白底`。

本仓库是公开仓库，不要上传用户尚未授权公开的实拍商品图、具体私有设计参考图、账户密码等。Skill中使用的照片是会话提供的临时输入，并不随此公开安装包分发。每天增量规则更新由用户设置的 ChatGPT 自动任务执行，GitHub Actions只负责在main更新后重新打包zip。
