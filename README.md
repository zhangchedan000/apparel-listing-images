# apparel-listing-images

服装商品套图生成 skill，适用于 ChatGPT（网页版 skill / Project）、Hermes、OpenClaw（小龙虾）。

## 用法
```
TK美区 白底卖点图解
亚马逊 3D立体展示 加字
亚马逊 真人模特展示
TK美区 白底卖点图解 组合装 黑+灰+蓝
TK SKU 灰色
```
核心：模板只是骨架，卖点、细节、排版、模特都根据具体商品决定。
流程：传商品图 → 确认商品档案 → 确认清单 → 回复 1 逐张出图 → 尺码图（提供真实尺码）→ 交付。

## 模板
| 模板 | 亚马逊 | TK美区 |
|---|---|---|
| 白底卖点图解 | 7 张 | 8 张 |
| 3D立体展示模版 | 7 张 | 8 张 |
| 真人模特展示 | 7 张 | 8 张 |
| 差异化对比（测试中） | 7 张 | 8 张 |

规格：两平台均 3:4、1600×2133。

## 目录
```
SKILL.md            入口：指令识别、流程、硬性规则
platforms/          平台规格

shared/             尺码图、模特、文案、提示词片段、自检清单
```

## 修改
- 加平台：新增 `platforms/xxx.md`，在 SKILL.md 指令识别表里加一行
- 加模板：新增 `templates/xxx.md`，同上
