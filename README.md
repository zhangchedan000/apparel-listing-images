# apparel-listing-images

服装商品套图生成 skill，适用于 ChatGPT（插件 / 技能）、Hermes、OpenClaw（小龙虾）。

## 用法
```
TK美区 白底卖点图解
亚马逊 3D立体展示 加字
TK美区 真人模特展示 组合装 黑+灰+蓝
TK SKU 灰色
```
流程：传商品图 → 确认商品档案和卖点 → 确认清单 → 每次回复 1 出一张 → 提供尺码出尺码图 → 交付。

## 模板与张数
| 模板 | 亚马逊 | TK美区 |
|---|---|---|
| 白底卖点图解 | 8 张 | 9 张 |
| 3D立体展示 | 8 张 | 9 张 |
| 真人模特展示 | 8 张 | 9 张 |
| 差异化对比（测试中） | 8 张 | 9 张 |

第 1、2 张为正面纯白 + 正面加元素（亚马逊纯白在前，TK 加元素在前）；亚马逊尺码图在第 7 张，TK 在第 9 张。规格 3:4、1600×2133。
