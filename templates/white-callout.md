# 模板：白底卖点图解

**风格**：隐形模特（ghost mannequin），纯白背景，无真人。后几张用英文卖点 + 图标 + 圆圈/方块特写解释商品。
**点缀色**：取自商品本身的主色（如棕色外套 → 棕色图标、标签条、虚线）。

## 张数
- 亚马逊 7 张：展示 3 + 卖点细节 3 + 尺码图
- TK 8 张：展示 3 + 卖点细节 **4** + 尺码图

## 结构
| 序号 | 类型 | 内容 |
|---|---|---|
| 1 | 白底正面主图 | 隐形模特正面平视；拉链款可敞开露出内里（以原图为准）；**无任何文字和图形** |
| 2 | 白底 3/4 侧角度 | 斜约 45°，展示立体版型；无文字 |
| 3 | 白底背面 | 纯背面；无文字 |
| 4 | 卖点圆圈图 | 一侧整件商品，另一侧 3–4 个圆形特写；每个特写配图标 + 标题 + 一句说明，用虚线连到商品对应部位 |
| 5 | 细节标签图 | 一侧商品，另一侧 2–3 个圆角方块特写，每块下方一条主色标签（只有标题） |
| 6 | 材质放大镜图 | 局部大特写（如内里、面料），一个圆形放大镜 + 1–2 个图标标注 |
| 7 | **仅 TK**：卖点细节补充 | 选前面没覆盖到的卖点，版式从 4/5/6 中选一种 |
| 末张 | 尺码图 | 见 `shared/size-chart.md` |

## 规则
- 第 4–7 张的卖点**不重复**，每张讲不同部位
- 卖点按商品档案实际特点选（加绒、连帽、拉链、口袋、罗纹袖口、压纹面料等）
- 版式按商品形状调整：竖长商品时特写可以放上下；卖点少时圆圈放大，不硬凑数量
- 虚线的落点必须准确指向商品上对应的部位

## 证据图
细节图中至少一张为证据图，用来证明主卖点（见 `shared/differentiation.md`）。指令带“对比图”时，用对比图替换一张普通细节图。
