# 模板：3D立体展示模版

**风格**：3D 立体隐形模特实拍效果——衣服像穿在看不见的人身上，饱满立体；纯白背景。细节图为微距实拍感。默认整套无文字（用户说"加字"时细节图加短标签）。

## 张数
- 亚马逊 7 张：3D 展示 3 + 细节 3 + 尺码图
- TK 8 张：3D 展示 3 + 细节 3 + **真人上身正面 1** + 尺码图

## 结构
| 序号 | 类型 | 内容 |
|---|---|---|
| 1 | 3D 立体展示·正面 | 正面平视，袖子自然垂下，**不翻袖口、不加特效** |
| 2 | 3D 立体展示·背面 | 纯背面 |
| 3 | 3D 立体展示·侧面 | 侧面或 3/4 角度，展示厚度和版型 |
| 4–6 | 细节实拍特写 | 每张只拍一个部位：帽子、领口、袖口罗纹、抽绳/气眼、拉链、口袋、面料纹理、内里等 |
| 7 | **仅 TK**：真人上身正面（见 `platforms/tiktok-us.md`） |
| 末张 | 尺码图 | 见 `shared/size-chart.md` |

## 细节图规则
- 微距、浅景深、柔和自然光，背景白色或浅灰
- 画面只有一个部位，面料纹理清晰
- **有细节实拍图 → 以实拍图为参考**；没有 → 只拍主图里能看清的部位，**不编造结构**（拉链头形状、抽绳扣样式等）
- 选哪些部位按商品档案决定，优先选最能体现卖点的部位
