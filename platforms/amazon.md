# 亚马逊（美国）· 服装

## 规格
| 项目 | 要求 |
|---|---|
| 比例 | **3:4 竖版**（官方服装指南：主图最低接近 3:4） |
| 输出尺寸 | **1600×2133 px**（最长边 ≥2000 可放大；最低 1000） |
| 格式 | JPG（sRGB），不要带透明通道的 PNG |
| 单张大小 | ≤10 MB |
| 张数 | **7 张**（前台通常显示前 7 张，尺码图必须在第 7 张以内） |

## 主图（第 1 张）
- 背景**纯白 RGB(255,255,255)**，不能偏白
- 商品完整，不被裁切，**占画面面积约 85%**
- **禁止**：文字、Logo、水印、徽章、边框、特效图形（火焰、圆圈等）、非售卖的配件或道具
- 成人服装：真人模特 / 平铺 / 隐形模特均可；**不能看到人台或衣架**
- 童装：主图只能平铺，不能用儿童模特
- 主图只能有这一件商品（多件装除外）
- **多件装**：主图必须平铺或隐形模特，**不能用真人模特**；包里几件就展示几件

## 辅图（第 2–7 张）
- 可以有文字、图标、场景、特写
- 比例与主图一致（3:4）

## 提醒
- 亚马逊对主图要求真实商品照片；AI 生成主图存在审核风险，有实拍图时优先以实拍图为底修图
