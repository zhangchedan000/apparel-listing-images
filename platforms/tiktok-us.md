# TK美区（TikTok Shop US）· 服装

## 规格
| 项目 | 要求 |
|---|---|
| 比例 | **3:4 竖版**（按 TK 新指南：无边框 3:4 首图，商品占满画面） |
| 输出尺寸 | **1600×2133 px**（最低 600×600） |
| 格式 | JPG / PNG |
| 单张大小 | **≤5 MB**（导出时压缩） |
| 张数 | **8 张**（≥5 张才能达到 Good 等级；最多 9 张） |

## 主图（第 1 张）
TK 政策写得严、实际执行宽松，热卖款主图普遍带卖点元素。**第 1 张默认出两个版本，让用户自己选**：

- **1A 纯白无字**（合规，最稳）
- **1B 加元素**：清单里先列出根据本商品卖点选出的元素（最多 3 种），用户可以修改
- 仍是一次一张：先出 1A，再出 1B，然后请用户选一个；没选中的不再使用
- 用户选中的版本决定后续 SKU 图、组合装第 1 张用哪种方式
- 用户在指令里已经说了"加元素"或"合规" → 只出对应的一个版本

### 加元素（1B）
**元素必须由卖点表里已确认的卖点决定**，不能套用；没有对应卖点的元素一律不用。

| 元素 | 用法 | 什么时候用 |
|---|---|---|
| 保暖火焰圈 | 圆形绒里特写 + 火焰描边，放在角上 | 只用于确认了"保暖 / 加绒"卖点的商品；短裤、T 恤、薄款绝不能用 |
| 翻边露绒 | 下摆或袖口翻起露出绒里 | 只用于真有绒里的商品，且必须与实物一致 |
| 件数标签 | `3PCS` / `2PCS` / `1 PIECE` | 组合装；单件可选 |
| 小图标卖点列 | 竖排最多 3 个细线图标 + 短词 | 图标和短词对应已确认的卖点（如加绒款 Thick Fleece；夏装 Breathable、Stretch Fit） |
| 色块 | 一排小圆点表示可选颜色 | 有多个颜色变体，且与实际变体一致 |
| 卖点标题 | 一句短标题，≤4 个单词（如 `WARM WINTER JACKET`） | 对应主卖点 |

- **每张最多 3 种**；放在边角，**不压商品主体**，商品仍占画面约 80%
- 风格统一干净：细线图标、中等字重，不用大号斜体、不堆砌
- 背景：纯白或浅色（浅灰、浅色大理石、与季节相符的淡场景）
- **仍然禁止**：价格、折扣、Sale、Best Seller、#1、评分、水印、边框、拼图（多格）；Windproof / Waterproof / Quick Dry 等可验证说法须用户确认
- 交付时提醒一句：主图带元素存在被驳回的风险，被驳回时改用 1A

### 纯白无字（1A / 指令加"合规"）
- 纯白背景、正面视角，**不加任何叠加元素**（文字、徽章、贴纸、数量标签、色块、Logo、水印、边框、拼图）
- 商品占画面约 80–85%，无边框

## 辅图（第 2–8 张）
- 每张展示不同角度或细节，**不能重复同一角度**（重复会被判违规）
- 服装类目要求视角 / 姿势 / 场景多样，部分类目要求**真人模特展示**；同一张图只换颜色不算多样
- 文字、图标：只写买家好处，简短；**禁止促销字眼**（价格、折扣、Sale、Best Seller、#1、排名、评分）

## 真人上身图（TK 专属）
- "白底卖点图解""3D立体展示""差异化对比"三套在 TK 上，**倒数第二张固定为 1 张真人上身正面图**（TK 是注意力驱动，买家要看上身效果）
- 只有这一张模特图，按 `shared/model-rules.md` 选模特；白底或浅灰棚拍，无文字

## 提醒
