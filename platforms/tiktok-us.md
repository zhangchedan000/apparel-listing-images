# TK美区（TikTok Shop US）· 服装

## 规格
| 项目 | 要求 |
|---|---|
| 比例 | **3:4 竖版**（按 TK 新指南：无边框 3:4 首图，商品占满画面） |
| 输出尺寸 | **1600×2133 px**（最低 600×600） |
| 格式 | JPG / PNG |
| 单张大小 | **≤5 MB**（导出时压缩） |
| 张数 | **8 张**（≥5 张才能达到 Good 等级；最多 9 张） |

## 主图（第 1 张）
TK 政策写得严、实际执行宽松，热卖款主图普遍带卖点元素。因此分两种模式：

### 默认：竞品模式
主图可以加卖点元素，从下面选，**每张最多 3 种**，按卖点决定：
| 元素 | 用法 |
|---|---|
| 保暖火焰圈 | 加绒 / 保暖款：一个圆形绒里特写 + 火焰描边，放在角上 |
| 翻边露绒 | 下摆或袖口翻起露出绒里（必须与实物一致） |
| 件数标签 | 组合装：`3PCS` / `2PCS`，单件可用 `1 PIECE` |
| 小图标卖点列 | 竖排最多 3 个细线图标 + 短词（如 Thickened、Soft Fleece） |
| 色块 | 一排小圆点表示可选颜色（与实际变体一致） |
| 卖点标题 | 一句短标题（如 `WARM WINTER JACKET`），≤4 个单词 |
- 元素放在边角，**不压商品主体**，商品仍占画面约 80%
- 风格统一干净：细线图标、中等字重，不用大号斜体、不堆砌
- 背景：纯白或浅色（浅灰、浅色大理石、淡雪景）都可以
- **仍然禁止**：价格、折扣、Sale、Best Seller、#1、评分、水印、边框、拼图（多格）；Windproof / Waterproof 等可验证说法须用户确认
- 交付时提醒一句：主图带元素存在被驳回的风险，被驳回时改用合规模式重出第 1 张

### 合规模式（指令加"合规"）
- 纯白背景、正面视角，**不加任何叠加元素**（文字、徽章、贴纸、数量标签、色块、Logo、水印、边框、拼图）
- 商品占画面约 80–85%，无边框

## 辅图（第 2–8 张）
- 每张展示不同角度或细节，**不能重复同一角度**（重复会被判违规）
- 服装类目要求视角 / 姿势 / 场景多样，部分类目要求**真人模特展示**；同一张图只换颜色不算多样
- 文字、图标：只写买家好处，简短；**禁止促销字眼**（价格、折扣、Sale、Best Seller、#1、排名、评分）

## 真人上身图（TK 专属）
- "白底卖点图解""3D立体展示""差异化对比"三套在 TK 上，**倒数第二张固定为 1 张真人上身正面图**（TK 是注意力驱动，买家要看上身效果）
- 只有这一张模特图，按 `shared/model-rules.md` 选模特；白底或浅灰棚拍，无文字

## 提醒
- **AI 生成的图（尤其是真人模特 / 场景）上架时要勾选 AI 内容声明**
- 第一次上架时检查后台预览，确认 3:4 没被裁切；若被裁切，告知用户改方案
