# 经验库

开工前读一遍，做图时主动避开。这里只记规则里没写、实际做图踩出来的坑；每条写成"问题 → 怎么避免"，一两句话。
增量更新：新经验加到对应分类，补充合并进原条，不重复、不按日期记流水账；和规则重复的不写。

## 细节和五金
- 口袋旁拼色条、织带上的字、金属抽绳头最容易漏 → 档案里单独列出来
- 罗纹束脚被画成松紧收口，压纹被画成 V 形或菱格绗缝 → 档案里写明"不是什么样"
- 看不清的字被编成假字（如 "FASIION"） → 看不清就做成无字
- 深色商品被画成一片死黑 → 提示词要求保留面料纹理和褶皱
- 只写 "black zipper pull"，模型换成通用拉头 → 原图先拆分齿链/布带、滑块、连接件、实体拉片及印字织带，分别记录形状、颜色、比例和证据；有特写就附对应位置
- 主拉链头和口袋拉头互换，口袋装饰字样被挪到主拉链，印字带甚至被画成第二个滑块 → 先按画面位置分别核实真实滑块数量、连接件和装饰带，再用独立编号与对应特写锁定
- 左右说反（穿着的人的左右和画面左右相反） → 一律按画面左右说
- 只让改中间主拉链头，侧面口袋拉头也被改了 → 框选只改那一处，提示词写明其他五金不动，只附要改那个零件的原图
- 零件被放大、衣服被拉长或压扁 → 各部位按原图相对比例，不为突出卖点放大零件
- 主拉链滑块被上移到领口，但原拉片/连接环仍在胸口或被换成别款 → 滑块、连接件和拉片作为原有同一组一起移动，口袋拉头不随之改变

## 整套一致
- 第 2、3 张开始拉头、口袋、Logo 走样 → 角度不变的图在第 1 张上编辑，不重新生成；必须重新生成的，附第 1 张 + 部件原图局部
- 后面的图参考了上一张已走样的图 → 每张都写明以认可的第 1 张为准
- 对话里图片太多后越做越乱 → 新开对话，只带第 1 张、原图和档案继续
- 细节图把整套风格、角度带偏 → 细节图只用来确认那个部位长什么样

## 第 1 张
- 第 1 张错了后面全错 → 出完提醒用户仔细对照原图
- 照搬了原图的平铺形状、褶皱、侧拍角度、敞开状态 → 原图只用来认商品，摆放和角度重新设计
- 3D 图胸腹撑起来了，袖子肘部以下还是塌、堆横褶 → 提示词写明双袖从肩到袖口均匀撑起
- 侧面原图只看到一侧口袋，转正面时漏了另一侧（反复出现） → 档案里写明"口袋共 X 个"并让用户确认，提示词里写清口袋数量和左右位置，附可见那一侧的口袋细节图

## 角度
- 背面图被画成正面（对话里正面图太多会带偏） → 背面图只附原图里的背面照，不附正面图，提示词写明只看得到背面

## 卖点图与排版
- 黑色加绒马甲旧版 A/B/C 的圆形或卡片做得过大，主体被挤向左侧，缩略图里卖点抢过商品 → 先锁已确认商品母版并以商品为第一视觉焦点；右侧组件按画幅和真实服装宽高自适应缩小，A 文案优先放圆圈下方，腾出横向空间让商品适度居中；重复组件仍用固定坐标对齐。
- 卖点 C 的绒毛微距曾超出正方形右边和底边，被画布截成残缺圆形 → 出图前按圆心、半径和安全边距校验整个圆框及阴影范围；空间不足就缩小并移位，绝不裁切微距边框或为了它挤压商品。
- 同一套蓝色/金色文字条机械复用到不同颜色商品，配色不贴合衣服 → 每款从衣身、绒里、五金提取克制的主文字色与强调色，黑色米黄绒马甲可用暖灰、米金，其他款重新选色。
- C 图有时增加底部三枚图标虽然丰富，但重复、抢主微距或写了未经核实的保暖性能 → 不一律禁止辅助图标；只在能说明真实同一核心卖点、并且不抢商品时由设计师决定保留 0–3 枚，未经证实的性能词不写。
- 图标分散在四个角 → 集中排成一列放一侧
- 虚线没指到真实部位、细节卡标签一张一个位置 → 虚线终点对准部件，标签统一在同一角
- 右侧三组卖点反复出现**图标看似差不多、但完整外框宽高不同**，第三组变窄、边框/圆角/标题条长短不一、图标在框内偏心、整列偏上或偏下 → 不只锁三个图标：先把「外框＋图标单元＋图片区/标题条＋文本框」做成一个完整母组件，再复制为三组；固定相同外框 W/H、共同 X 中线、同样的 Y 净间距，并把整列居中在右侧可用区，文字长短只在固定文本区内换行。错位时仅修右侧，不动已确认商品。
- 即便提示词写了“同宽、对齐、等间距”，A 图仍出现圆圈直径、圆心和标签**外框**不一，B 图的三张卡片与标题条无法严格统一 → 不能把三组完整组件交给 AI 逐个自由绘制；按右侧内容区先算定统一 `W_box/H_box`、共同 `X_center` 和 `Y_i=Y_0+i×(H_box+Gap)`，优先用确定性排版复制母组件，再填真实局部与短英文；仅靠提示词不能保证像素级一致，不声称已经精准统一，也不为对齐重绘商品。
- 4 张精简套图里 B 被画成纯图标列表、C 又变成三张细节卡，A 的圆形特写忘了连到衣服 → 出图前按 A=圆形特写加真实部位虚线、B=纵列 2–3 细节卡、C=单项微距分别核对图上结构，不拿别的卖点版式替代。
- 材质放大镜图把两种面料拼成上下两块 → 主体是衣服局部，放大镜连到原位置
- 尺码图重画了衣服、写了"量身体"、"下摆"标成 Waist → 在第 1 张上加线和表格，按数据类型写说明，下摆标 Hem
- 尺码图把原始表里肩宽、袖长、建议身高体重等全部搬进成品，还重复画多组说明卡，导致商品变小、测量线繁杂 → 上衣仅筛选 Waist/Chest/Length，裤子仅筛选 Waist/Hip/Length；原表缺项直接略去，最多 3 项，商品上仅画对应测量线，配一张简洁表格，不添加说明卡或多余特写；不得将肩宽或下摆宽当作腰围。
- 转尺寸时把带灰底的图缩小贴进白框 → 换成连续的纯白背景

## 模特
- 衣服像把原图贴在人身上 → 写明真实穿着、自然贴合
- 手插在不存在的口袋、插错位置 → 先出垂手图，再框选袋口编辑插手；只插锁定表里标"能插"的口袋
- 手机放口袋时拉链闭合、手机却穿出来 → 拉链真正打开，手机进袋被布料挡住一部分

## 流程
- 一轮要求出多张，被合成一张拼图 → 对话界面坚持每轮一张
- 回复里放了网上搜的"示意图"，用户以为是做出来的 → 只放生成的商品图
- 自检不通过自动重做，卡住流程 → 出图后不自我判定，交给用户
- 只要求修一处，别处跟着变 → 局部编辑 + 框选，一次只改一处

## 组合装 / 多颜色 SKU
- 多色合照被做成前大后小或四件散开并排 → 用户要「等比例斜向阶梯层叠」时，四件等比例、正面竖直，从左下向右上紧凑错位，主要露出后件颜色而非大面积衣身；按件数微调间距和画面占比。
- 后件横向露出太多、上下落差太大，主体显小 → 缩小每层平移距离，让后件只露领帽、肩部和少量侧边，整组适度放大；不能靠拉伸或单独缩放某件来凑版。
- 不同颜色共用一套拉链头、印字织带或抽绳，甚至把颜色选项写成多件装 → 每色分别核对齿链、滑块、连接件、拉片、印字方向及纹理；只有明确实售多件装才加件数标签。

## 营销主图
- 小图标做得太大、不在一条竖线上、外圈被画面边缘切掉 → 提示词写明图标直径约画面宽度 6–7%、圆心在同一竖线、离边缘留 5%、外圈完整；出问题就框选图标列单独编辑

## 画幅与防变形
- 1:1 和 3:4 不能互相拉伸转换 → 必须按用户开工时选定的画幅重新排版；1:1 用主体优先的正方形逻辑，3:4 沿用原竖版逻辑。
- 先做完 1:1 再“改成”3:4，最容易把衣长压短、卖点位置失衡或留白关系错乱 → 直接用同一商品母版重新计算主体位置、组件尺寸和安全边距，不拿上一种成品硬改。
- 双尺寸模式最容易漏掉“先让用户选尺寸”这一步 → 商品识别后先确认平台，再确认尺寸，再选模板；清单里把尺寸单独列出来。
