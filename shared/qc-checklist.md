# 每张出图后的自检清单（全部通过才交付）

**通用**
- [ ] 只有一个画面，无拼图 / 宫格 / 分屏
- [ ] 比例 3:4；尺寸按平台
- [ ] 内容与清单本张一致，没有和前面某张重复构图
- [ ] 商品与原图一致：颜色无偏差、结构无增减（对照商品档案逐项核对）
- [ ] 商品没有被拉伸 / 压缩变形
- [ ] 无塑料感 / 渲染感，面料有真实褶皱

**主图**
- [ ] 背景符合平台（亚马逊纯白 RGB 255）
- [ ] 亚马逊 / TK 纯白主图：无文字、Logo、水印、边框、特效
- [ ] TK 加元素：元素 ≤3 种且每个都对应已确认的卖点（不出现与品类不符的元素，如短裤上的保暖火焰）、在边角不压商品、无价格折扣排名字眼、件数和色块与实际一致
- [ ] 商品完整，占画面约 85%

**有文字的图**
- [ ] 文字与清单逐字一致，拼写正确
- [ ] 文字不压商品，元素不重叠，留白均衡，缩略图下能看清
- [ ] 虚线 / 箭头指向的部位正确

**真人模特**
- [ ] 与第 1 张是同一个人（肤色、身材、发型、下装、鞋）
- [ ] 手、手指、脸正常
- [ ] 年龄、性别符合清单

**组合装**
- [ ] 件数和颜色与用户给的完全一致
- [ ] 所有商品在同一张照片里，不是拼格子
- [ ] 整组横向撑满约 85–90%，无大片空白
- [ ] 后面的每件都能看清颜色和领口
- [ ] 缩略图大小下一眼能看出几件、什么颜色

**尺码图**
- [ ] 每个数字、尺码顺序与用户数据逐格一致
- [ ] 只有用户给的部位；测量线位置正确

**失败处理**：不通过直接重做，同一张最多重做 2 次；仍不通过就停下，告诉用户哪里不行。
