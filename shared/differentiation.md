# 差异化提炼与对比图

**铁律：差异化只从用户提供的资料里提炼，必须真实。** 宣传和实物不符 → 差评、退货。AI 只负责把真实的差异讲清楚、画出来，不负责编造差异。

## 资料来源（由用户提供）
- **自己的商品资料**：文字（工厂参数、面料克重、填充量、尺码范围、做工说明）或图片（实拍、细节、内里剖面、吊牌、详情页）
- **竞品资料（可选）**：同价位竞品的截图 / 链接、差评截图、便宜款实拍图

## 提炼步骤（放在卖点分析之前）
1. **整理竞品**（有资料时）：竞品在讲什么卖点、用什么图、**差评里抱怨什么**（绒薄、掉毛、起球、尺码偏小、口袋浅等）
2. **对照自己的资料**，找出真实更强的地方，常见来源：
   - 用料：绒更厚、克重更高、填充更多
   - 做工：双线缝合、拉链质量、罗纹紧实
   - 功能细节：多一个口袋、拉链口袋、可调节帽子
   - 版型和尺码：尺码范围更大、尺码表更准
   - 价值：多件装单价更低
3. **竞品差评的痛点 = 最好的卖点**，前提是我们真的解决了这个问题
4. 每条差异化写明**依据来自哪份资料**，标"需确认"，用户确认后才能用
5. **没有任何差异化资料** → 只讲品类核心卖点（保暖、舒适），并提示用户："补充商品参数或竞品资料可以做出差异化"

### 防水 / 防风措辞（必须按用户确认的程度写）
| 实际性能 | 可以写 | 不能写 |
|---|---|---|
| 面料泼水、小雨不湿 | Water-Resistant / Water-Repellent | Waterproof |
| 有防水测试数据（如压胶、防水指数） | Waterproof（附用户提供的数据） | — |
| 面料挡风 | Wind-Resistant / Blocks Wind | Windproof（除非有测试依据） |
用户只说"防水"但没有测试数据 → 默认写 Water-Resistant，并在卖点表里提醒用户。

## 证据图（每套至少一张）
细节图里至少一张用来**证明主卖点**，而不只是展示部位：
- 保暖 → 内里厚度的剖面 / 侧面特写、手捏绒里显示厚度
- 舒适 / 柔软 → 面料拉伸、手抚面料的特写
- 做工 → 缝线、拉链、罗纹近距离特写
证据必须与商品原图和用户资料一致，不能夸大厚度或效果。

## 对比图（可选，指令加"对比图"才做）
淘宝常见的"普通款 vs 我们"对比。

**前提**
- 每一项对比都必须是用户确认的真实差异；最好有便宜款实拍图作参考
- 普通款画成"市面常见便宜款"的正常样子，**不能故意画烂、不能夸大**
- 普通款**不能有任何品牌、Logo，不能像某个具体竞品**，只标 `Ordinary` / `Others`

**画面（3:4）**
- 左右或上下两栏：`Ordinary` vs `Ours`
- 对比 2–3 项，每项都是**同一部位**的特写（如绒里厚度、袖口罗纹、缝线）
- 普通款与我们的商品：同款式、同色系、同光线、同角度，**只有被对比的那一项不同**
- 我们：✓ + 一句好处；普通款：✗ + 一句客观问题（如 `Thin lining, less warm`）

**平台**
- TK：可以做，替换一张普通细节图
- 亚马逊：平台不允许与竞品比较，**不做"普通款 vs 我们"**。说"亚马逊 + 对比图"时，自动改做下面的亚马逊替代图

## 亚马逊替代图（"亚马逊 + 对比图"时使用）
从下面两种里选一种（按用户资料决定，两种都能做时优先 A），替换一张普通细节图：

**A. 结构分层图（推荐）**
- 把衣服"剖开"展示：外层面料 → 填充 / 保暖层 → 内里，一层层错开排列，每层旁边一句作用
- 例：`Wind-Resistant Shell` → `Warm Padding` → `Thick Sherpa Lining`
- **每一层都必须与用户提供的面料资料一致**；资料里没有的层不画（如没有填充层就只画外层 + 内里）
- 用"可验证说法"（windproof、具体克重等）前必须用户确认

**B. 数据证据图**
- 用真实参数说话：内里厚度特写 + `Thick 300GSM Fleece`；手捏绒里显示厚度
- 数字（克重、填充量、厚度）只能用用户提供的真实数据

**C. 自家产品对比（用户单独要求时）**
- 只比自己的产品：单件 vs 多件装（突出单价更划算）、标准款 vs 加厚款
- 每一格数据来自用户资料
