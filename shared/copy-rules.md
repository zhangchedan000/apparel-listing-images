# 卖点文案、加字开关、视觉风格

## 卖点来源
- 提炼方法见 `shared/selling-points.md`（品类核心需求 → 买家顾虑 → FAB → 主卖点）
- 证据只从商品档案里取，按每个商品的实际特点定
- **可验证的说法**（材质成分如 100% Cotton、防水 Waterproof、防风、保暖温度、羽绒含量等）**必须用户确认属实才能写**，AI 不能根据图片推测
- 以利益点为主：`Soft fleece keeps you warm`，少用无法证明的绝对化说法（best、warmest、#1）

## 禁用字眼（两平台通用）
- 价格、折扣、Sale、Deal、Best Seller、#1、Top Rated、评分星级、Free Shipping 等促销 / 排名字眼一律不写

## 文字长度
- 标题 ≤4 个单词，Title Case（如 `Thick Warm Lining`）
- 说明 ≤12 个单词
- 一张图上的文字只用清单里确认过的句子；出图后逐字核对拼写

## 加字开关
- 指令后带"加字"（如"亚马逊 3D立体展示 加字"）→ 该模板的细节图每张加一个英文短标签（标签条或角标，只有标题）
- 不带"加字" → 3D立体展示、真人模特展示的细节图保持纯图
- **主图永远不加字**

## 视觉风格（统一）
- 字体：英文粗体无衬线（如 Montserrat / Poppins 风格）；标题粗体，说明常规
- 点缀色：从商品主色取色（图标底色、标签条、虚线、圆圈描边）
- 深色商品（黑 / 深灰）→ 点缀色用中性深灰或商品的辅色，保证可读
- 同一套图字体、颜色、图标风格完全一致
