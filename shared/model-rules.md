# 模特规则（美区）

- **姿势**：正面展示为主，站姿自然放松，不僵硬
- **性别**：男装 → 男模特；女装 → 女模特；中性款 → 在清单里问用户
- **年龄**：匹配商品目标人群（看款式、版型、风格），**中年款不能用年轻模特**
  - 潮流 / 修身 / 街头风 → 20–30 岁
  - 基础休闲款 → 30–45 岁
  - 宽松舒适 / 中老年款 → 45–60 岁
  - 判断不准 → 清单里写"建议 XX 岁"，让用户确认
- **形象**：美国本地形象；身材匀称自然，不用夸张模特身材
- **族裔**：不固定；每个商品在清单里写建议（如"男，35–45 岁，白人"），由用户确认；店铺层面适当轮换
- **一致性**：同一套图只用同一个模特
- **下装 / 鞋**：中性、不抢镜（如上衣配深色长裤 + 简洁运动鞋），全套一致
- **真实感**：真实皮肤质感，不要 AI 网红脸，不过度精修；重点检查手
